# 실험 설계 및 결과 분석

## 1. 문제 발견

기존 10에포크 고정 학습에서 훈련 손실은 마지막 **0.553**까지 감소했으나 검증 손실은 **Step 100 약 2.683 → Step 315 4.039**로 증가. 학습 데이터와 검증 데이터 간 예측 성능 차이가 확대되어 과적합 징후로 판단.

## 2. 개선 가설

검증 손실을 주기적으로 평가하고 개선이 중단된 경우 학습을 종료하여 **검증 성능이 가장 좋았던 가중치**를 보존하면, 무조건 10에포크까지 학습한 최종 모델을 사용하는 것보다 검증 성능 저하를 피할 수 있다는 가설.

### 통제 및 변경 요소

| 항목 | 기존 실험 | 추가 실험 |
|---|---|---|
| 데이터 | 동일 금융 AI 텍스트 | 동일 |
| 모델 | GPT 구조, 무작위 초기화 | 동일 |
| 학습 설정 | AdamW, batch 2, 최대 10에포크 | 동일 |
| 종료 조건 | 10에포크 완료 | **검증 손실 미개선 10회 평가** |
| 모델 선택 | 마지막 시점 | **최저 검증 손실 시점** |

5 optimizer step 간격으로 검증 손실 평가. 조기 종료 시 최적 체크포인트 로드 후 검증 손실 재측정.

## 3. 실험 결과

| 측정값 | 결과 |
|---|---:|
| Baseline 최종 에포크 / Step | 10 / 315 |
| Baseline 최종 훈련 손실 | 0.553 |
| Baseline 최종 검증 손실 | 4.039 |
| Baseline 최저 검증 손실 | 약 2.683 (Step 100) |
| Early Stopping 종료 에포크 / Step | 5 / 150 |
| Early Stopping 최적 에포크 / Step | 4 / 100 |
| Early Stopping 종료 시 검증 손실 | 2.8293 |
| 최적 모델 복원 후 검증 손실 | **2.6831** |
| Baseline 최종 모델 대비 검증 손실 변화 | **약 33.6% 감소** |

동일 학습 데이터·설정에서 반복한 실험으로, 기존 기록과 신규 기록의 최저 손실은 사실상 같음. 따라서 성과는 **새로운 최고 성능 확보**보다 **후반 과적합 구간의 학습 중단과 모델 선택의 자동화**에 해당.

5에포크에서 종료돼 에포크 수가 10 대비 절반으로 감소했으나, 이를 GPU 실행 시간이나 비용이 정확히 50% 절감됐다는 뜻으로 볼 수 없음.

## 4. 문장 생성 관찰

영어·한국어 시작 프롬프트 모두 자연스러운 금융 문장을 생성하지 못했으며, 한글 반복과 유니코드 대체 문자(`�`) 확인. 프롬프트 언어 비교는 **동일 Early Stopping 최적 모델에 대한 보조 실험**으로, Baseline 모델 대비 생성 품질 개선의 증거는 아님.

## 5. 해석상 주의

- 같은 검증 세트로 모델 선택과 결과 보고를 수행. 독립 테스트셋에서의 일반화 개선을 직접 입증하지 않음
- 단일 데이터 분할·단일 실험 조건으로 통계적 유의성 평가 불가
- 금융 정보 정답률, RAG 검색 정확도, 환각 감소율 등은 평가 대상 아님
- GPT 모델 구조와 기본 훈련 코드는 수업 실습을 기반으로 하며, Early Stopping 및 비교 로직은 후속 실험으로 추가
